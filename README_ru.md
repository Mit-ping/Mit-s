# Mit's VPN

VPN-приложение для Windows x64 с интерфейсом и функциями телефонной Beta 1.5.
Текущая Windows-версия: **1.5.0-beta.2**.

- Одна кнопка подключения и неоновая тема Mit's VPN.
- VLESS + REALITY и AmneziaWG, включая клиентские ключи Amnezia.
- Импорт из буфера обмена, `.vpn`, `.conf`, `.txt` и QR-изображений.
- Выбор, переименование и удаление профилей.
- Россия и локальная сеть — напрямую; остальной трафик — через TUN.
- Автовосстановление с ограниченными повторами и приоритетами резервных профилей.
- Автозапуск Windows, работа через системный трей, безопасный диагностический отчёт.
- Проверка обновлений Windows по нажатию, сверка размера и SHA256 до запуска EXE.

## Windows-сборка

Workflow [windows-build.yml](.github/workflows/windows-build.yml) собирает
установщик EXE и portable ZIP, выполняет анализ, тесты и проверку запуска окна.
Результаты находятся в артефактах GitHub Actions. Этот workflow не публикует релизы.

[Подробности и ограничения](docs/windows-1.5-beta.md).

## Авторы и лицензия

Mit's VPN основан на открытом проекте [Hiddify](https://github.com/hiddify/hiddify-app).
Исходные авторы и условия использования перечислены в [LICENSE.md](LICENSE.md)
и [NOTICE.txt](assets/legal/NOTICE.txt), доступных также внутри приложения.
Изменения этой версии: Windows-брендинг, новая иконка, перенос телефонного
интерфейса, импорт QR-файлов, восстановление сети и Windows-обновления.
Служебные API, имена стороннего VPN-ядра и его системной службы сохранены
для совместимости с опубликованными бинарными компонентами.
