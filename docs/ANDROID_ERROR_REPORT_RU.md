# Отчёт о последнем подключении Android

В меню главного экрана под «Настройки» находится «Отчёт об ошибке».
Откроется просмотр с двумя действиями:

- **Скачать отчёт** — выбрать место сохранения TXT через системный диалог Android;
- **Поделиться** — открыть системное меню и выбрать Telegram, затем получателя.

Файл одинаков для обоих действий. Открытие Telegram не объявляется доставкой:
получателя и отправку сообщения пользователь выбирает в Telegram.
Автоматической отправки, сетевого обработчика и токена бота в приложении нет.

Перед каждой ручной или автоматической попыткой создаётся новый журнал.
Хранятся время UTC, протокол, этапы, распознанные типы ошибок и последнее
известное состояние. Сохраняется только последняя попытка (до 200 событий)
в приватном каталоге приложения; она доступна после перезапуска. Если приложение
завершилось до события остановки, окончание обозначено как «не зафиксировано».
Без предыдущего подключения можно сохранить отчёт о текущем состоянии.

Исходные строки журналов не экспортируются. Ошибки DNS, TLS, таймауты,
отказ в разрешении, ошибки профиля/интерфейса и недоступность сети представлены
фиксированными кодами. Неизвестный текст скрыт. Нет ключей, паролей, адресов
серверов, посещённых сайтов, имён/идентификаторов профилей и рекламных ID.
Это диагностический журнал, а не полная трассировка сетевого трафика.

Отмена системного диалога не считается сохранением. При ошибке файл можно
повторно сохранить или отправить другим способом; подробности платформенного
исключения в интерфейс не выводятся. Новые разрешения Android не требуются.

Сборка с отчётами имеет Android versionCode **50006** и прежний сертификат.
Workflow ветки `feat/android-error-report` создаёт подписанный APK в артефактах;
GitHub Release этим заданием не публикуется.
