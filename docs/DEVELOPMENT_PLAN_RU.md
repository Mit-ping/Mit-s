# План разработки Android VPN

## Правила работы

Работаем в существующем checkout и отдельной ветке, без дополнительного worktree.
После каждого этапа фиксируем изменения, реально выполненные проверки и следующий
шаг. Незавершённую проверку не считаем успешной. Сервер Xray не меняем; реальные
профили и ключи не попадают в репозиторий, CI, артефакты диагностики и PR.
Новые возможности пилота включаются только на Android; совместимость iOS и Windows
проверяется перед объединением изменений в основную ветку.

## Этапы и критерии завершения

1. **Основа и аудит.** Уточнить MVP, проверить существующее подключение, профильный
   импорт и маршрутизацию; сохранить аудит и план.
   Статус: аудит и первоначальный Android-пилот в ветке `feat/android-one-tap-pilot`.
   См. [аудит](ANDROID_ONE_TAP_STAGE1_RU.md). Запрошенные исходные kickoff-документы
   отсутствуют; пользователь поручил самостоятельно выбрать первый этап.
2. **Воспроизводимая сборка.** Получить закреплённый Flutter/Android SDK, выполнить
   codegen, анализ и тесты. Подготовить отдельную CI-сборку без production-секретов.
   Статус: завершён на GitHub Actions. Генерация, анализ, тесты пилота, полный
   набор тестов и проверка конфигурации iOS прошли
   [в этом запуске](https://github.com/Mit-ping/Mit-s/actions/runs/41052296087).
   Первые запуски выявили несовместимость SQLite 3.37.2 (Ubuntu 22.04) со строгим
   режимом Drift SchemaVerifier. Сбой отдельно воспроизведён; на SQLite 3.46.1
   запрос проходит. Runner переведён на Ubuntu 24.04, добавлен preflight строгого
   режима. Миграции приложения не изменены. Локальный SDK пока блокируется сетевой
   политикой, но удалённый путь сборки работает.
3. **Первый скачиваемый APK.** После успешных анализа, тестов и сборки получить
   `one-tap-vpn-debug.apk` и SHA-256, проверить установку на Android.
   Статус: APK собран и загружен. [Успешная сборка и скачивание](https://github.com/Mit-ping/Mit-s/actions/runs/41052296087).
   Artifact: `one-tap-vpn-debug-30f7447221f1c63da575cbe77ed5fc466cce3c12` (246 MB).
   В ZIP находятся `one-tap-vpn-debug.apk` и `SHA256SUMS`; хранение — 14 дней.
   Пользователь подтвердил скачивание, установку и запуск приложения на Android.
4. **Проверка настоящего VPN.** На устройстве проверить permission, connect/disconnect,
   отмену, ошибки REALITY, поведение при смене сети и восстановлении приложения.
   Проверить фактический egress российских и зарубежных адресов, DNS и IPv6.
   Подтвердить, что недоступность rule-set не создаёт незаметного обхода политики.
   Статус: пользователь подтвердил добавление профиля, подключение VPN и открытие сайтов. Базовый туннель работает по результатам проверки на устройстве. Фактическая раздельная маршрутизация, DNS, IPv6 и смена сети пока не подтверждены. Профиль вводится только локально.
5. **Дизайн.** Выбрать название, цвета, типографику; согласовать макеты домашнего экрана,
   импорта и управления профилями, состояний подключения и ошибок. Макеты можно
   обсуждать параллельно, внедрение — после проверки базового туннеля.
   Статус: пользователь предоставил референс Mit’s VPN в чёрно-зелёной неоновой палитре. Синий концепт заменён этим направлением; см. [дизайн-бриф](DESIGN_BRIEF_RU.md).
6. **Реализация дизайна.** Перенести утверждённые экраны, определить миграцию старых
   профилей и убрать лишние пути Android-интерфейса, не меняя другие платформы.
   Повторить функциональные тесты; выпустить новый тестовый APK.
   Статус: собственный интерфейс Mit’s VPN реализован; по видеореференсу добавлена
   «матрица» с белой кнопкой до соединения и плавное появление Анонимуса/зелёного
   свечения после успешного подключения. Анализ, тесты пилота, полный набор,
   рендеры и APK прошли [в CI](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226).
   [Актуальный APK — ZIP, 252 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226/artifacts/13035331756);
   [превью — ZIP, 2,81 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226/artifacts/13035206014).
   Ожидается проверка этой версии на Android.
7. **Версия для использования.** Доработать защиту профилей и логов, стабильность,
   accessibility, обновления и подпись. Проверить совместимость и подготовить
   подписанный APK с инструкцией установки. Production-ключ хранится вне Git.

## Как получить APK через GitHub Actions

Workflow `.github/workflows/android-one-tap.yml` запускается при push в ветки
`feat/android-one-tap-*`. Для него не нужны production signing secrets и он
не публикует релизы. Все проверки должны пройти до загрузки APK-артефакта.

1. В репозитории открыть **Actions → Android one-tap APK**.
2. Выбрать успешный запуск с нужным коммитом ветки.
3. Скачать artifact `one-tap-vpn-debug-<полный SHA>` и распаковать ZIP.
4. Проверить `SHA256SUMS` и установить `one-tap-vpn-debug.apk` на тестовое устройство.

Это debug-сборка с временной подписью и существующим application ID Hiddify.
Она может конфликтовать с установленным Hiddify по подписи. Использовать чистое
тестовое устройство/эмулятор или отдельный Android-профиль; не удалять рабочий
Hiddify без безопасного сохранения его профилей. Подпись может меняться между
CI-запусками, поэтому обновление поверх предыдущего тестового APK не гарантируется.
Стабильная идентичность нашего приложения и release-подпись — отдельная задача
до распространения. Debug APK не предназначен для постоянного использования.

## Формат отчёта об итерации

* Сделано.
* Проверено (с отдельно указанными ошибками и незапущенными проверками).
* Что можно посмотреть или скачать.
* Следующий шаг и конкретный внешний блокер, если он есть.


### Предыдущая итерация: белая кнопка и брендинг

Пользователь запросил белую кнопку по умолчанию, зелёную при подключении и собственные
иконку/запуск/все обычные экраны Android. Реализация, анализ и тесты прошли
[в CI](https://github.com/Mit-ping/Mit-s/actions/runs/41074011746).
[Новый APK, ZIP 252 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41074011746/artifacts/12985919499),
[рендеры, 4,02 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41074011746/artifacts/12985469115).
APK дополнительно проверен на имя приложения, launcher identity и bundled assets. Лицензионное авторство сохранено отдельно. Проверка именно этой версии на
устройстве ещё предстоит; внутренний application ID сохранён для совместимости профилей.


### Текущая итерация: переход после успешного подключения

По видеореференсу пользователя добавлены «матрица» без фигуры до соединения
и плавное появление текущего фона/зелёной кнопки только после `Connected`.
Длительность — 900 мс, с обратным переходом при отключении и поддержкой
уменьшения анимации.

Проверенный код: `f8417f33dc2e349c05546a3ff5dbabf963d945e9`.
[CI завершён успешно](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226): анализ, тесты пилота, полный набор тестов,
экспорт рендеров, сборка APK и проверка упакованных ресурсов прошли.
[Скачать APK — ZIP, 252 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226/artifacts/13035331756),
[рендеры экранов — ZIP, 2,81 МБ](https://github.com/Mit-ping/Mit-s/actions/runs/41181216226/artifacts/13035206014).
Установка и визуальная оценка анимации именно этой версии на Android ещё предстоят.


### В работе: AmneziaWG

Пользователь запросил AWG, приоритетный формат — клиентская ссылка `vpn://` из
Amnezia. Добавлен проверяемый импорт этого формата, `.conf`/`.txt` и `awg://`;
безопасные подписи протокола и тесты, включая настоящий native core.
Подробности и ограничения: [AmneziaWG](AMNEZIAWG_RU.md).
Анализ, CI и APK этой итерации ещё ожидаются. Проверка реального AWG-соединения
будет выполняться на устройстве с ключом пользователя, без передачи ключа в чат.
