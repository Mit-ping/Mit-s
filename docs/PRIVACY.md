# Mit's VPN: данные приложения

Профили и настройки сохраняются на устройстве. Ключи профилей используются
для подключения к выбранному вами VPN-серверу. Не публикуйте их вместе с отчётами.
Безопасный отчёт на странице восстановления содержит только версию и состояния;
сырые технические логи могут содержать дополнительные сведения.

При ручной проверке и загрузке обновлений приложение обращается к GitHub.
Проверка SHA256 подтверждает целостность относительно манифеста выпуска;
она не заменяет цифровую подпись издателя Windows.

Вы сами выбираете сервер и управляете маршрутизацией. Российские ресурсы
и локальная сеть по умолчанию исключены из VPN. Строгая маршрутизация TUN
в Windows действует во время работы туннеля и не равнозначна системной
Android-блокировке всего трафика после остановки приложения.
