Mit’s VPN — Beta 1.5 · сборка 50006

• Добавили «Отчёт об ошибке» под «Настройки» в меню главного экрана. В отчёте — время, этапы и распознанные ошибки последнего подключения. Его можно сохранить в TXT или отправить через «Поделиться», например в Telegram. Ключи, адреса серверов и посещённые сайты не включаются.
• Добавили экран обновлений: проверка новой версии, список изменений и скачивание APK прямо в приложении.
• Перед установкой проверяются целостность APK, пакет, номер версии и совпадение подписи. Установку подтверждает Android.
• Подключили новый постоянный ключ подписи к GitHub Actions. После установки версии с этим сертификатом последующие сборки с тем же ключом и большим номером версии смогут обновляться поверх с сохранением профилей и настроек.
• Добавили импорт клиентского VPN-профиля по QR-коду. Камера открывается по нажатию; добавление требует подтверждения.
• Профилям можно задавать свои названия.
• Порядок резервных профилей теперь можно менять стрелками.

Маршрутизация по умолчанию сохранена: российские домены/адреса из используемых списков и локальная сеть — напрямую, остальной трафик — через VPN при подключении.

Важно: у этой сборки новый сертификат подписи. Android не установит её поверх версии, подписанной другим ключом. Перед переходом сохраните исходные VPN-ссылки и файлы профилей. Не удаляйте старую версию, пока эти данные не сохранены: удалённые данные приложения новый APK автоматически не восстановит. Экспорт профилей не добавляли.
